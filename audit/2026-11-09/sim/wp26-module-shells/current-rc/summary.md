## Screen heights

Informational only (Q5): it changes neither the TAP result nor
any exit code. A screen starts at a clear sequence and ends at
the next practice prompt (or at the end of the run for the
finale). The count is the newline-terminated lines of normalised
output in between, so the blank line the screen helper adds and
the practice footer printed just before the prompt are included.
Logical lines are counted; a long line that wraps is one line.
Where one screen id has several clears (Ctrl+L, `clear`), the
largest is shown. Budget (A11): 20 rendered lines before the prompt,
the 19-row panel (header through lower rule) plus the blank row
under it, so the prompt lands on row 21 of a 24-row terminal.
`Lines` is the raw rendered count.
